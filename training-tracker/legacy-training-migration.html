Legacy Training Data Migration

Bringing Jackie's existing "MANDATORY Training – ALL STAFF (Cadets)" SharePoint list (CdtsTrainingMatrix) into Training Tracker — 81 people, 13 courses, ~896 training records, plus certificate attachments — without hand-typing any of it. This is a multi-package build: each package is a small, independently-testable Power Automate flow you import as a .zip, not one giant flow.

Why packages instead of one big flow: this touches real people's real training records. Each package below does one job, can be tested on its own, and nothing writes real data until you explicitly run the write-capable package with dry run off. If a package fails to import or misbehaves, the blast radius is just that one package.

Package 1 — Discover Source Fields

Read-only. Runs one SharePoint query (/_api/web/lists/getbytitle('CdtsTrainingMatrix')/fields), returns every column's real internal name, and writes nothing anywhere.

Download

TT_Discover_Source_Fields.zip — import package, ~2.5KB.

Steps

  1. Download the zip above.
  2. Power Automate → My flows → Import → Import Package (Legacy) → upload the zip.
  3. It will list one dependency: your SharePoint connection. It should already show your existing connection — if it says "Select during import," pick your normal SharePoint account. Click Import.
  4. Once imported, open TT - Discover Source List Fields from My flows.
  5. Click Test (top right) → Manually → Test again to confirm. It takes no inputs, so it runs immediately.
  6. Once it finishes, click into the run, open the final Response step, and copy the full JSON output.
  7. Send that JSON back — paste it in chat, or drop it as a .json or .txt file in the homepage upload box.
What happens next: once I have the real internal column names, Package 2 gets built against them specifically (not guessed), and this page gets updated with its download link and steps the same way.
