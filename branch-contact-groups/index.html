Branch Contact Groups - Current Task

v2.45 fixes the noticeable delay when saving a group edit, adding someone, or clicking most action buttons on Manage Groups and Manage People. Every one of those actions ended by silently re-fetching every membership for every group from SharePoint, one group at a time — the same slow pattern behind the old loading-dots bug, just triggered by buttons this time instead of navigation. Every one of those actions now updates the already-loaded local copy directly, using the exact data just written, so nothing gets re-fetched. The explicit Refresh button is untouched — it's supposed to do a full reload. Only scrManageGroups and scrManagePeople changed this round — Quick Contacts, Send Email, and App.OnStart are untouched.

Still open, not yet diagnosed: a popup/lightbox (e.g. Manage Members) disappearing while scrolling. Need more detail before this can be fixed properly — which screen, and whether it happens scrolling the page behind the popup or a list inside the popup itself.
